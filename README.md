# Friends' Game

Пиксельная мультиплеерная игра про дружбу. Временные комнаты без регистрации — зашёл, сыграл, вышел, комната удалилась.

## Что уже работает (MVP)

- Главный экран: имя, случайный аватар, создать/войти в комнату
- Комната: список участников, 8-символьный код, копирование ссылки
- Режим «Насколько вы знаете друг друга»: 10 раундов, 3 жизни, таймер
- Real-time синхронизация через WebSocket (Socket.io)
- Пиксельная тёмная тема, помехи, появление вопроса по словам
- Сравнение ответов через AI (embeddings) или простой fallback

## Архитектура

```
Браузер (Next.js React)
    ↕ WebSocket (Socket.io)
Custom Node-сервер (server/index.ts)
    ├── Комнаты в памяти (Map) — удаляются когда все вышли
    ├── Игровой движок (раунды, жизни, вопросы)
    └── AI-модуль (сравнение смысла ответов)
```

**Без профилей:** игрок хранится только в `localStorage` (id, имя, аватар). Комната живёт в RAM сервера и удаляется, когда последний участник отключается.

**Для продакшена** позже можно добавить Redis (комнаты с TTL) и деплой на Railway/Render/Fly.io.

## Запуск локально

### 1. Установить зависимости

```bash
npm install
```

### 2. Настроить AI (выберите один вариант)

Скопируйте `.env.example` в `.env`:

```bash
copy .env.example .env
```

#### Вариант A — Groq (рекомендуется, бесплатно)

1. Регистрация: [console.groq.com](https://console.groq.com)
2. Создайте API key
3. В `.env`: `GROQ_API_KEY=gsk_...`

Используются две модели Groq:
- **Вопросы и реплики Neko-01** — `qwen/qwen3-32b` (хороший русский; можно заменить на `llama-3.3-70b-versatile`)
- **Проверка ответов по смыслу** — `llama-3.1-8b-instant` (быстрый YES/NO)

Лимит бесплатно: ~14 400 запросов/день (~450 полных игр). Ответ за доли секунды.

#### Вариант B — OpenAI (платно)

1. [platform.openai.com](https://platform.openai.com) → API key
2. В `.env`: `OPENAI_API_KEY=sk-...` (без `GROQ_API_KEY`)

#### Вариант C — Ollama (локально, свой сервер)

1. [Ollama](https://ollama.com) → `ollama pull nomic-embed-text`
2. В `.env`: `OLLAMA_URL=http://localhost:11434`

#### Вариант D — без AI

Простое сравнение слов (синонимы не понимает).

### 3. Музыка (опционально)

Положите файл `public/music/tension.mp3` — напряжённую мелодию. Кнопка «Музыка» на экране включает её.

### 4. Запуск

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

**Тест с двумя игроками:** откройте два окна браузера (или обычное + инкognito), создайте комнату в одном, войдите по коду во втором.

## Что делает нейросеть, а что нет

| Задача | Источник |
|--------|----------|
| **Вопросы в раундах** | Groq (Neko-01), сложность растёт с раундом; запасной список в `questions.ts` |
| **Проверка ответов по смыслу** | Groq (YES/NO) или fallback |
| **Реплики Neko-01** | Groq с промптом-манипулятором |

Чтобы изменить запасные вопросы (если Groq недоступен) — массив `QUESTIONS` в `server/game/questions.ts`.

## Как работает проверка ответов

Для каждого игрока два ответа:
1. **О себе** — факт о себе
2. **О друге** — что игрок думает, ответит друг

Проверка: «догадка игрока A» сравнивается с «ответом о себе игрока B» через LLM-судью (Groq) или embeddings (OpenAI/Ollama).

Пример: друг ответил «голубые», ты написал «синие» — AI засчитает как верно.
